# 🐙 DARKHUB

## 📖 نظرة عامة

**DARKHUB** هو منصة خارقة لرفع وربط الإسكربتات، مصممة خصيصاً للهاكرز والمطورين. تتيح لك رفع أي ملف، والحصول على روابط تحكم وتشغيل فورية.

## 🚀 الميزات الرئيسية

- ✅ تنزيل الملفات بسهولة

## 📦 التثبيت

### المتطلبات
- Python 3.8+
- pip
- virtualenv (اختياري)

### الخطوات
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/darkhub.git
cd darkhub

# 2. إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # أو venv\Scripts\activate على Windows

# 3. تثبيت الاعتماديات
pip install -r requirements.txt

# 4. إعداد ملف البيئة
cp .env.example .env
# عدل الملف بإضافة المفاتيح المطلوبة

# 5. تشغيل الخادم
python backend/server.py

# 6. فتح المتصفح
http://localhost:5000
