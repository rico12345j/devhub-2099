# ☁️ Render Clone

## 📖 نظرة عامة

**Render Clone** هو نسخة مقلدة من منصة Render الشهيرة، تم بناؤها باستخدام **Python** و **Flask** و **SQLite**. توفر المنصة جميع الميزات الأساسية التي تجعل Render منصة النشر السحابي الأولى في العالم.

## 📦 التثبيت

### المتطلبات
- Python 3.8+
- pip
- virtualenv (اختياري)

### الخطوات
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/render-clone.git
cd render-clone

# 2. إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # أو venv\Scripts\activate على Windows

# 3. تثبيت الاعتماديات
pip install -r requirements.txt

# 4. إعداد ملف البيئة
cp .env.example .env
# عدل الملف بإضافة المفاتيح المطلوبة

# 5. تشغيل الخادم
python backend/server.py

# 6. فتح المتصفح
http://localhost:5000
